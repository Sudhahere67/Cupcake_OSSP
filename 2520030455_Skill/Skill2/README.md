# Skill Exercise 2 – Interactive Shell and Keyboard Input

## Objective

To develop an interactive command-line loop and understand keyboard input
handling using C.

## Programs

1. shell_loop.c
   - Displays a shell prompt.
   - Reads user input.
   - Handles the exit command.
   - Supports multi-character commands.

2. keyboard_input.c
   - Captures keyboard input.
   - Handles the Enter key.
   - Handles Backspace.
   - Stores input in a buffer.

## Compilation

make

## Execution

./shell_loop
./keyboard_input

## Testing

Use test_commands.txt for testing different inputs.

## Tools Used

Linux
GCC
C
Make

## Outcome

The exercises demonstrate how an interactive shell accepts and processes
user input and how keyboard characters can be captured and managed.
