# OSSP 24 Skill Program Documents

These documents follow the format of the supplied Experiment-2(Skill) document:
Name, Roll No, Section, Experiment No., Title, Aim, Objective, Theory, Algorithm,
Functions Used, Sample Input/Output, Observation, Result, Part 2 Linux Commands
Observation, Hardware and OS Relationship, Conclusion, Code, OUTPUT and SCREENSHOT.

All programs are intended for Ubuntu/Linux and GCC.

## Compile
gcc -Wall -Wextra q01.c -o q01

## Run
./q01

Replace the sample/output placeholders with actual Ubuntu terminal screenshots before submission.
